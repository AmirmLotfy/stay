Status meanings:

- **Completed**: the planned hackathon action is finished.
- **Verified live**: deployed behavior or provider state directly proves the requirement.
- **Verified in CI**: current automated tests prove the deterministic contract.
- **External gate**: a real participant, physical device, or provider decision is still required.
- **Time gate**: the stated observation period has not elapsed.
